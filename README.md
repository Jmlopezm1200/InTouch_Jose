- crear una nueva branch y te cambia a esa rama
 git checkout -b jose/agregar-dashboard

- hacer los cambios

- agregar los cambios al stage area
  git add .

- hacer un commit 
  git commit -m "lo que sea"

- hacer push de la rama
  git push

- cambiar de rama
  git checkout nombre-de-la-rama

- traer cambios
  git pull

- revisar el estado del repo
  git status


# Recomendaciones
- mantener main actualizado siempre
- crear ramas para cada cambio
- hacer pull requests
